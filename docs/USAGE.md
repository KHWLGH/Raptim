## 开始使用与启动参数

首次运行会在数据目录自动创建 `raptim.db`，并预置「常用 / 默认分类」。所有数据直接放在数据目录里，不会额外建 `data` 子目录，也不会往 `AppData` 写入业务数据。

支持通过命令行参数控制数据目录与启动形态：

```powershell
# 默认方式：在 raptim.exe 同级目录读写 raptim.db
.\target\release\raptim.exe

# 便携模式：显式指定与默认相同的 EXE 同级目录
.\target\release\raptim.exe --portable

# 独立数据目录：适合多库隔离、开发或试用
.\target\release\raptim.exe --data-dir C:\Temp\RaptimTrial

# 静默启动：开机自启或后台驻留使用
.\target\release\raptim.exe --silent
```

- `--portable` 与 `--data-dir` 不能同时使用；如果数据目录不可写，或者目录里的数据库结构无法识别，启动时会直接弹窗报错，不会暗中切换目录或改写原有文件。
- `--silent` 仅在首次启动阶段生效：如果已开启「贴边自动收纳」并记录过停靠边缘，主窗口会直接收在屏幕边缘且不抢焦点；否则保持完全隐藏，仅驻留在系统托盘里。
- 按数据目录隔离单实例：在同一数据目录下再次启动 `raptim.exe`，会直接唤醒已有实例并自动退出新进程（同样受游戏勿扰策略控制）。

## 界面布局与浏览

主窗口采用 Fluent 样式与系统圆角，名称输入和部分管理确认保留为窗内浮层：

| 区域 | 说明与行为 |
| --- | --- |
| 标题栏 | 左侧为图标与拖动区，右侧依次为搜索、添加、临时固定图钉、「更多」菜单与关闭按钮；**关闭按钮用于隐藏窗口**（可通过托盘、热键或再次启动呼出），不设最小化按钮 |
| 横向分组栏 | 展示一级分组并支持横向滚动，末尾「＋」按钮可就近新建分组（空白处不弹菜单） |
| 左侧分类栏 | 展示当前分组下的二级子分类，名称支持自动换行和纵向滚动，末尾「＋」按钮可就近新建子分类（空白处不弹菜单） |
| 项目视图区 | 支持网格（小 28 px 最多 5 列 / 中 36 px 最多 4 列 / 大 48 px 最多 3 列，窄窗自动降至最少 2 列）与单列列表视图；点击卡片不保留高亮底色，键盘焦点移动时显示细描边 |
| 悬停提示与状态条 | 悬停项目时显示名称、完整路径或网址以及最多 6 行备注；底部状态提示会在 6 秒后自动收起，相同提示自动合并并保留最新消息 |

当分类栏或项目区为空时，窗口内会直接提供「添加项目」与「扫描导入」快捷入口，也可以直接向窗口拖入文件或网址。

## 项目管理与组织

### 添加、编辑与目标类型

点击标题栏「＋」或按 `Ctrl+N` 打开独立编辑窗口（单页滚动表单）：

| 类型 | 说明与专属字段 |
| --- | --- |
| `程序` | 本地可执行文件（含可选参数、工作目录、以管理员身份运行、打开方式：普通 / 最大化 / 最小化） |
| `文件` | 任意本地或 UNC 路径文件 |
| `文件夹` | 本地或网络目录 |
| `网址` | 支持省略协议（如 `example.com` 自动补全为 `https://example.com`），仅接受 `http://` 或 `https://` |
| `快捷方式` | `.lnk` 快捷方式文件路径，支持配置打开方式（普通 / 最大化 / 最小化） |
| `应用 AUMID` | 通过「从应用列表选择」打开窗内本机 `shell:AppsFolder` 列表筛选回填，并提取应用图标 |

- **所属分类树**：通过分组 → 分类展开树选择目标位置（方向键浏览、`Enter` 选中、`Esc` 仅收起树不丢失表单）。
- **图标提取与拖入**：文件/程序/快捷方式优先提取 256 px Shell 图标后缩至 128 px 入库；网址仅在保存编辑、外部拖入或手动「刷新图标缓存」时联网抓取页面 `<link rel="…icon…">`（优先大尺寸）或 `/favicon.ico`（启动回填不联网）。编辑窗口支持拖入单张 PNG / JPEG / ICO 图片作为自定义图标（单文件上限 16 MB、4096×4096）。
- **未保存保护**：编辑窗有未保存改动时关闭或按 `Esc` 会二次确认；按 `Ctrl+Enter` 可直接保存。

### 外部拖入与批量导入

- **Explorer / 浏览器拖入**：支持一次拖入最多 500 个文件/目录/快捷方式或浏览器网址文本；拖放到左侧某个子分类上直接进入该分类，拖放到其他区域进入当前分类；同分类重复目标会自动跳过并提示数量。
- **扫描导入软件**：通过「更多 → 扫描导入软件…」、空白右键或空分类提示按钮打开；后台扫描系统开始菜单（全部用户与当前用户目录最深 4 层 `.lnk` / `.url`，自动过滤卸载/说明/帮助/协议及程序自身）和 `AppsFolder` 打包应用，排除当前分类已有目标后支持关键字筛选、全选与勾选批量导入。

### 拖拽排序、分组/分类管理与多选整理

- **拖拽防误触与排序**：在项目区按住左键至少 **180 ms** 且移动至少 **12 DIP** 后才会激活拖拽排序，快速大幅滑动松手不会误触发启动或排序；网格下以目标卡片左右半区、列表下以上下半区显示插入指示线。
- **分组与分类管理**：分组和分类均支持同级拖拽排序、切换目标及删除；分类右键「移动到分组」可将整个子分类迁往其他一级分组；在分组或分类上按 `F2` 可就地改名，删除时支持把内容迁移到同级其他位置（同名分类自动编号，空默认分类不保留），也可勾选「不迁移，直接删除其中的项目和子分类」，系统强制至少保留一个一级分组。
- **多选整理**：从项目区空白右键或标题栏「更多 → 多选整理」进入批量模式，支持单击多选、`Shift+单击` 连选、`Space` 勾选与 `Ctrl+A` 全选；底部三等分面板提供「移动到…」「复制到…」「删除」（仅移除启动器记录，保留原文件），移动或复制遇到重复目标时整批取消并保持当前选择。

### 路径转换与失效项目检查

- **批量路径转换**：通过「更多 → 路径转换」选择转为相对路径或绝对路径，提供分组/分类树形多选（支持半选状态）、全选/清空与转换预览；以 `raptim.db` 所在目录为基准同时转换程序路径与工作目录，跨驱动器项目跳过并保留原值。
- **检查失效项目**：通过「更多 → 数据 → 检查失效项目…」启动后台巡检（跳过网址，核查本地文件/目录、`PATH` 命令与已安装 AUMID 列表），对异常条目提供「重定位」「编辑」「移除」三个直达操作。

## 搜索与快捷键

点击标题栏放大镜或按 `Ctrl+F` 打开窗内搜索浮层；在常规设置开启「获焦后直接打字搜索」后，主窗口获焦状态下直接输入非空白可见字符也会自动打开搜索浮层并填入首字。

- **搜索范围**：支持切换「全部」「当前分组」「当前分类」。
- **匹配与排序**：对项目名称、别名（支持空格或中英文逗号、分号、顿号、`|` 分隔）、备注（**不检索目标文件路径**）执行多关键词与全拼/逐字首字母/词首首字母/驼峰首字母匹配，按精确/前缀/包含/全拼/首字母/备注相关度排序；输入法组合期间按 `Enter` 只确认候选词，不会误启动项目。

| 快捷键 | 作用域 | 功能 |
| --- | --- | --- |
| `Ctrl+Alt+Space`（默认） | 全局 | 呼出主窗口；窗口已展开且聚焦无弹窗时再次按下则收起或隐藏 |
| `Ctrl+F` | 主窗口 | 打开并聚焦搜索框 |
| `Ctrl+N` | 主窗口 | 打开「添加项目」窗口（非内联编辑、非批量模式且未聚焦搜索框时） |
| `Ctrl+,` | 主窗口 | 打开设置窗口（非内联编辑时） |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 主窗口 | 切换到下一 / 上一个子分类 |
| `↑` `↓` `←` `→` / `Home` `End` | 主窗口 | 在项目网格中移动键盘焦点（搜索打开时 `↑` `↓` 切换结果） |
| `Enter` | 项目 / 搜索结果 | 启动当前选中项目（批量模式下切换选中状态） |
| `Shift+Enter` | 项目 / 搜索结果 | 触发「使用管理员打开」 |
| `Alt+Enter` | 项目 / 搜索结果 | 打开选中项目的编辑窗口 |
| `F2` | 导航 / 项目 | 焦点在分组/分类上就地改名；焦点在项目上打开编辑窗口 |
| `Delete` | 项目网格 | 弹出删除当前选中项目确认框（非搜索、非批量模式） |
| `Space` | 批量模式 | 切换当前选中项目的勾选状态 |
| `Ctrl+A` | 批量模式 | 全选当前视图全部项目 |
| `Esc` | 主窗口（分层） | 依次关闭：扫描/失效面板 → 批量目标/确认 → 删除/重定位/转换面板 → 弹出菜单 → 内联输入框 → 批量模式 → 搜索浮层 → 清除选中 → 隐藏主窗口 |
| `Ctrl+Enter` / `Esc` | 编辑窗口 | 直接保存 / 关闭（有未保存改动时先确认） |

## 菜单与系统托盘

所有应用内上下文菜单按操作语义插入分隔线分段渲染，支持键盘跟踪、浅深色主题与多级展开：

- **标题栏「更多」与空白区右键**：窄窗口下项目区空白较少，因此「空白区右键」菜单段（多选整理、添加项目…、添加文件…、扫描导入软件…、图标大小、列表查看、按名称排序）整体复用到「更多」菜单顶部；「更多」菜单下方追加「数据」（导出…、恢复…、检查失效项目…、打开数据目录）、「路径转换」、恢复窗口位置、设置… 与 退出。
- **项目右键**：打开 / 打开所在位置 / 复制路径或网址 → 编辑… / 重新定位… → 使用管理员打开 / Windows 原生菜单 / 创建桌面快捷方式 / 刷新图标缓存 → 移动到 / 复制到 → 排序 / 路径转换 → 删除…（排序项按真实前后边界自动置灰，不支持的项如网址/应用自动禁用路径类与管理员操作）。
- **分组与分类右键**：新建分组或子分类 / 编辑… → 排序 → （仅分类）移动到分组 → 删除…（仅剩最后一个分组时禁用删除）。
- **系统托盘**：右键划分为四段 —— 显示 Raptim / 恢复窗口位置 → 暂停自动隐藏 / 暂停游戏勿扰（可勾选，仅本次运行有效，与主窗临时固定及设置页开关双向同步）→ 设置 → 退出；左键单击托盘图标可直接显示主窗口，托盘提示文案显示当前全局热键。

## 贴边收纳与窗口控制

开启「贴边自动收纳」后，拖动主窗口贴近屏幕左、右或上边界（约 14 DIP 吸附阈值，下边不吸附）即可进入贴边状态：

- **悬停展开与离开收起**：指针移入露边感应带停留 **24 ms** 后自动滑出展开；移出窗口超过 **贴边收起延迟**（可选 150 / 250 / 450 ms，默认 250 ms）后平滑收起。通过热键、托盘、第二实例或启动主动呼出停靠窗口时，会保持展开直至获得并离开焦点或指针进入窗口后再恢复计时（避免刚呼出就秒收起）。
- **露边与动画**：支持开启/关闭露边及调节 **1–12 物理像素** 露边宽度（默认 1 px）；关闭露边时窗口在收起态完全隐身（DWM Cloak），仍可在原停靠边缘悬停 24 ms 或通过热键/托盘唤出。滑动采用保留反向速度的临界阻尼动画（系统关闭客户端动画时直接切换）。
- **辅助窗与聚焦保护**：打开设置、项目编辑、名称编辑覆盖层或系统文件选择框时，自动暂停失焦隐藏、贴边收纳与普通全屏隐藏计时；关闭前台辅助窗口时主动把焦点交回主窗口（后台关闭不抢焦点）。
- **未贴边失焦隐藏与临时固定**：未贴边时若开启「失去焦点时隐藏」，失焦等待 **100 ms** 后按 **100 ms** 淡出隐藏。点击标题栏图钉可临时固定（置顶并暂停自动隐藏，不落库）；在设置页开启「窗口始终置顶」则会持久化到本机状态并允许与贴边收纳并存。
- **恢复窗口位置**：若外接显示器断开导致窗口停留在不可见区域，可通过托盘、「更多」或设置页点击「恢复窗口位置」，解除贴边并把主窗口居中到最近显示器的工作区。

## 游戏勿扰保护

Raptim 会结合前景窗口与系统通知状态评估是否处于需要免打扰的全屏或游戏场景：

- **全屏保护**：默认开启，综合窗口几何尺寸与 Windows `SHQueryUserNotificationState`（D3D 全屏、演示模式、忙状态）阻止热键、托盘、第二实例或贴边悬停误弹出。普通全屏状态下，若之前打开了应用内设置/编辑等辅助窗口，辅助窗口仍优先维持可用；全屏信号消退后留有短暂防抖（常规 900 ms，系统处于忙状态时延长至 3000 ms）。
- **严格保护程序**：在「设置 → 游戏勿扰」中添加的程序路径列表（最多 100 项），只要前台窗口命中最先匹配的规则，立即进入严格保护，优先级高于临时固定、辅助窗口与自动恢复，并暂时屏蔽全局热键响应。
- **保护解除行为**：保护解除后，原本可见且未固定的贴边窗口仅恢复到边缘收纳态而不自动展开或抢焦点；手动隐藏的窗口不会自动恢复。
- **本次放行与判定日志**：可在托盘或设置页勾选「暂停游戏勿扰」（仅本次运行有效，不写入数据库）；需要排查为何未弹出时，可临时开启「记录保护判定」，在数据目录生成已脱敏的 `protection-log.csv`。

| | 打开项目后隐藏 | 启动项目后自动隐藏主窗口，默认关闭 |
| | 启动方式 | `单击`（默认）/ `双击` |

| | 失去焦点时隐藏 | 失焦延迟淡出隐藏主窗口，默认关闭 |

## 数据备份、导出恢复与故障排查

### 数据备份与导出恢复

- **数据目录直接备份**：应用不提供内置数据库备份快照。如需完整备份，**请先退出 Raptim，再将整个数据目录一起复制走**——`raptim.db` 在运行期间处于 WAL 模式，必须连同同级 `raptim.db-wal` 与 `raptim.db-shm` 一起复制，运行中只复制主文件会丢失尚未合并的数据。
- **JSON 导出与恢复**：
  - 导出会生成一份包含分组、项目和图标数据的 JSON 文件（图标采用 Base64 编码，且不会直接覆盖已有同名文件）；窗口坐标、停靠方向和「窗口始终置顶」属于本机状态，不包含在导出文件里。
  - 恢复时会先检查导出文件的字段完整性和结构兼容性，并按与数据库 `dup_key` 一致的规则校验同一分类内是否存在重复目标，发现冲突会直接拒绝并给出提示。校验通过后会在单笔数据库事务里原子替换全部业务数据，中途失败自动回滚；成功替换后不会额外保留旧文件副本，点击确认前请先自行备份数据目录。
  - 如果想先验证手头的数据库或 JSON 导出文件再替换正式数据，可以新建一个空文件夹放入 `raptim.db`，然后通过 `--data-dir <临时目录>` 启动预览。
- **格式校验与保护**：遇到无法识别的数据库或导出文件时，程序会直接报错提示并保持原文件不被改写。如果已有数据库中存在历史重复记录，程序仍可正常打开并仅阻止新增重复项。

### 启动失败与故障日志

- **项目启动失败重定位**：启动失败会区分目标已删除/移动、可移动设备未就绪、网络位置暂不可用、路径校验无效、取消管理员授权、访问被拒、无关联应用、打包应用未安装及其他系统错误；其中前四类本地路径暂时不可达的项目会在窗内弹出「重新定位」面板，只更新路径并清理旧图标缓存，原有参数、工作目录与打开方式都会保留。
- **常开错误日志**：数据目录里的 `error-log.txt` 会记录启动失败、未路由菜单命令和意外 panic（附带毫秒时间戳并对用户主目录、数据目录做 `<用户>` / `<数据目录>` 脱敏），超过 512 KiB 时自动截断前半段只保留近期记录。

## 文件与日志格式

### JSON 导出格式

通过「导出」生成标准 UTF-8 JSON 文件，顶层包含 `format_version`、`collections`、`entries` 与 `settings`（所有字段结构严格校验，不允许未知字段；`settings` 中缺失的可选字段会取默认值）：

```json
{
  "format_version": 2,
  "collections": [
    { "id": 1, "parent_id": null, "name": "常用", "position": 0 },
    { "id": 2, "parent_id": 1, "name": "默认分类", "position": 0 }
  ],
  "entries": [
    {
      "icon": "iVBORw0KGgo...",
      "id": 1,
      "collection_id": 2,
      "name": "记事本",
      "aliases": "notepad 笔记",
      "notes": "快速记录文本",
      "target": {
        "kind": "program",
        "path": "C:\\Windows\\System32\\notepad.exe",
        "arguments": "",
        "working_dir": "",
        "elevated": false,
        "show": "normal"
      },
      "position": 0
    }
  ],
  "settings": {
    "hotkey": "Ctrl+Alt+Space",
    "theme_mode": 0,
    "edge_hide": true
  }
}
```

- `icon` 字段为 PNG 字节的 **base64** 编码字符串（可为空字符串）。
- `target.kind` 支持六种类型与对应字段：`program`（`path`、`arguments`、`working_dir`、`elevated`、`show`）、`file`（`path`）、`folder`（`path`）、`url`（`url`）、`shortcut`（`path`、`show`）与 `app`（`aumid`），其中 `show` 取值 `normal`、`maximized` 或 `minimized`。
- 窗口几何、上次分组/分类及「窗口始终置顶」属于本机状态（保存在数据库 `local_state` 表中），**不随 JSON 导出**。

### 诊断日志文件

- **`error-log.txt`**：位于数据目录，常开只追加；格式为 `<Unix毫秒时间戳> <类别> <脱敏消息>`，例如：
  ```text
  1764165000123 menu-unrouted kind 0 command 99
  ```
- **`protection-log.csv`**：位于数据目录，仅在「设置 → 游戏勿扰 → 记录保护判定」开启后写入；首行为表头 `elapsed,kind,source,protection,detail`，后续每行记录被拦截或切换的保护状态与脱敏详情：
  ```csv
  elapsed,kind,source,protection,detail
  1764165012456,blocked,Hotkey,Fullscreen,geometry matched
  ```

## 常见问题

### 点击右上角关闭按钮后程序为什么还在运行，如何彻底退出？

Raptim 作为常驻快速启动器，标题栏关闭按钮的语义是**隐藏窗口**（不设最小化或收起按钮）。如需退出进程，请右键系统托盘图标或点击标题栏「更多」菜单，选择底部的 **退出**。

### 呼出热键无响应或在游戏全屏时无法弹出？

1. 检查热键冲突：若设置页记录的组合键已被系统或其他软件占用，保存或启动时会保留原热键并在托盘/状态条提示；可在「设置 → 呼出与隐藏」重新录制或恢复默认 `Ctrl+Alt+Space`。
2. 触发游戏勿扰：全屏窗口或命中「严格保护程序」列表时会拦截热键与托盘唤出。若需临时使用，可在系统托盘或「设置 → 游戏勿扰」勾选仅本次运行有效的 **暂停游戏勿扰**；若需排查拦截原因，可临时开启 **记录保护判定** 查看 `protection-log.csv`。

### 断开外接显示器后主窗口跑到屏幕外找不到？

右键系统托盘图标或在「更多」/「设置 → 呼出与隐藏」点击 **恢复窗口位置**，应用会取消贴边收纳并按当前尺寸将主窗口居中移回最近显示器的可见工作区。

### 移动 `raptim.exe` 或更换数据目录后，「开机启动」下面出现红色警告？

开机启动会在当前用户注册表的 `Run` 项写入固定可执行文件路径、`--data-dir` 与 `--silent` 参数。当程序路径变化、数据目录变更或在任务管理器启动项中被手动禁用时，设置页会校验并给出提示；按提示在「设置 → 常规」重新开关一次 **开机启动**（或在任务管理器恢复启用）即可更新。

### 打开数据库或恢复 JSON 时提示结构不兼容或重复目标错误？

- 遇到无法识别的表结构、外部数据库或字段校验失败的 JSON 导出文件时，程序会直接拒绝打开或导入，并原样保留文件不做修改。
- 同一子分类下不允许出现重复目标（例如一条用相对路径、另一条用绝对路径指向同一文件）。恢复前如果导出文件里存在这类冲突，请先清理后再导入。

### 为什么备份 `raptim.db` 前必须先退出程序？

`raptim.db` 在运行期以 SQLite **WAL 模式** 工作，最新写入可能尚未合并回主库文件而暂存在同目录的 `raptim.db-wal` / `raptim.db-shm` 中。请先彻底退出 Raptim，再将整个数据目录一并复制备份；若只需验证备份，可放进新的空目录后通过 `--data-dir <临时目录>` 启动预览。

### 为什么新加网址后图标稍后才显示，或重启后旧网址仍没有图标？

为保持启动轻快并尊重离线优先边界，添加或拖入网址时会先保存项目并在后台单条抓取站点图标（仅在新增保存、拖入和手动右键「刷新图标缓存」时联网）；启动阶段的空图标回填不会联网请求网页，若某条旧网址缺少图标，右键该项目选择 **刷新图标缓存** 即可重新抓取。
