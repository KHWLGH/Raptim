# Diascia

Diascia —— 基于 Lucy 重构研究推进的 Windows 本地启动器，Rust + Slint 应用工程。运行方式见下文“运行”一节，验证方式见“开发验证”。

主界面空白处右键可选择小／中／大图标（默认最多五／四／三列，窄窗自动减少）或列表，立即保存。分组标签横向滚动显示完整名称，子分类名称自动换行；两栏放不下时一律靠滚动查看，栏尾不再有「…」选择菜单。分组栏与子分类栏末尾各有一个「＋」就近新建分组／子分类，两栏的空白处都不弹菜单（新建只走「＋」和分组／分类项自己的右键），行为保持一致。运行时仅保留托盘入口，标题栏收起和关闭均隐藏窗口，托盘／热键可以再次呼出。托盘另提供「暂停自动隐藏」与「暂停游戏勿扰」两个可勾选入口，设置页的勿扰标签有同一个开关；放行只作用于本次运行，不写数据库。

设置、项目编辑、名称编辑及文件选择打开期间暂停失焦、贴边、启动后隐藏及普通全屏自动隐藏；明确配置的严格保护程序仍优先。关闭辅助窗口后重新开始隐藏计时。

关闭前台设置、名称或项目编辑窗口时主动将焦点交回主窗口，保留固定状态；后台关闭不抢焦点，已隐藏的主窗口不会被重新唤出。

## 运行

开发环境：Windows x64、Rust 1.92+、Visual Studio C++ Build Tools 与 Windows SDK。本次使用 Rust 1.98.1；最低 Rust 版本尚未实测。

```powershell
cargo run --release --locked
```

程序位于 `target/release/diascia.exe`。使用 Slint 1.18.0 Fluent 控件、winit Windows 后端和软件渲染器，不依赖 WebView、JavaScript 或 C#。

默认直接在 **EXE 同级目录**保存 `diascia.db`（含设置和项目图标），不创建 data 子目录、不写 AppData。首次运行建立版本 1 的新库，内含“常用”分组及真实的“默认分类”。

```powershell
# 便携模式：与默认相同，直接写 EXE 同级目录
.\target\release\diascia.exe --portable

# 独立数据目录：适合开发和试用
.\target\release\diascia.exe --data-dir C:\Temp\DiasciaTrial
```

目录不可写或数据库无法识别时会报错，不暗中切换目录。

## 近期实现记录

- 名称编辑与应用选择是主窗口／编辑器窗口内的覆盖层，不再有独立顶层窗口；设置窗口按需创建。启动复用已校验的数据快照。主网格按行虚拟化，图标在后台按可见范围解码并统一缩到 128 像素（新存入的图标同样以 128 像素保存，旧库里的 256 像素图标读取时降采样），解码缓存上限 24 MiB，完全隐藏时收缩到只剩可见范围。
- 第二实例改用系统事件通知；完全隐藏时不轮询，贴边收纳只做一次光标位置判断（光标远离揭示带时间隔 32 毫秒，靠近时 16 毫秒），贴边动画按帧时钟推进。热键、托盘和第二实例继续经过统一保护策略。
- 记忆主窗位置、尺寸、贴边方向及最后分组/分类；分类滚动位置和键盘焦点在当前会话中保留。显示器变化时将窗口限制在可见工作区。
- 搜索增加“全部／当前分组／当前分类”。仅从项目区空白右键或“更多 → 多选整理”进入多选；支持 Shift 连选、Ctrl+A 和分层 Esc。批量整理面板按三等分列排布，全选／完成与复制到…／删除上下对齐；批量移动/复制使用分组与分类树，卡片里的执行按钮与其余确认框一样高亮，确认后执行；成功后保留整理模式并清空选择，失败保留目标与选择。重复目标会取消整批操作，删除不影响原文件。
- 菜单按操作语义分段：分隔线由同一套 owner-draw 通道绘制（9 逻辑像素高、禁用项，所以鼠标和键盘都会跳过它），子菜单里的分段同样生效；空白右键那一段整体复用到标题栏“更多”，窄窗口不再需要赌运气点空白。
- 菜单树与命令归属搬到库里的纯数据（`diascia::menus::tree` / `region`），二进制只负责读状态填 `MenuContext`、开弹窗、按 `Region` 分派；菜单内容因此可以离屏断言，不再只能靠真点一次。顺带修掉两处一直存在的缺陷：八个菜单项沿用 `action()` 的默认字形（一张人像，包括分组／分类的“删除…”），以及恒为 `true` 的 `can-sort` 属性——排序项现在按 `Store::move_entry` 的真实边界置灰。
- 接入原生 OLE 文件和浏览器网址拖入；落在分类节点时进入该分类，其余位置进入当前分类。网址可省略协议（`example.com` 按 `https://` 补全），仍只接受 http/https，不联网获取标题。编辑窗口仍支持单张图片拖入。
- 窗口位置和“始终置顶”是本机状态，不随 JSON 导出。
- “呼出与隐藏”新增“窗口始终置顶”，允许同时贴边收纳；标题栏临时钉住仍会暂停自动隐藏。保护解除后，原来可见且未钉住的贴边窗口只恢复收纳入口，不自动展开、不抢焦点；手动隐藏不会自动恢复。
- 工具与项目提示统一使用主题表面、细描边和紧凑圆角。项目提示显示名称、完整路径或网址与备注，备注最多六行。编辑窗在原生句柄就绪后注册图片拖入，关闭时释放，并丢弃旧编辑会话的拖入回调。

具体测量方法、能证明什么与不能证明什么，见下文“开发验证”的三层划分。

## 当前功能

- 标题栏下方横向分组、左侧纵向分类；默认每行四个项目，窄窗自动减少列数，名称最多显示两行，悬停显示完整名称和路径。使用 Fluent 实色层次和系统圆角，移除染色外框。编辑与设置使用辅助窗口，关于并入设置标签。
- 分组、分类通过就近新建按钮和居中名称窗口创建、改名，不挤压项目区、同级排序、跨分类拖放、子分类移动及删除继续支持。删除时可以先把内容迁移到同级另一处，也可以勾选“不迁移”连其中的项目和子分类一起从 Diascia 移除（原文件不动）；迁移时同名分类自动编号，空的默认分类不保留。至少保留一个分组，两种删除方式都受此约束。不再显示虚拟“全部”；没有子分类的分组自动建立默认分类，落在分组上的项目迁入真实分类。
- 标题栏搜索按钮或 **Ctrl+F** 打开主窗内搜索浮层；支持名称、别名、备注、多关键词、拼音和首字母匹配，按相关度排序。上下键选择、Enter 启动，Esc 分层关闭。
- 设置按“常规、呼出与隐藏、游戏勿扰、数据、关于”排列；游戏勿扰页可选开启保护判定记录，写入数据目录并做路径脱敏，供排查游戏时被误呼出；右侧去掉重复页标题，使用紧凑等高行。开关和选择立即保存，文本仅保存合法输入。
- 贴边离开 150 ms 后收纳，悬停 40 ms 后展开；使用保留反向速度的阻尼动画，完整收纳约 155 ms、展开约 180 ms，短距离自动提前停稳。贴边状态下热键、托盘和第二实例也平滑展开；动画按刷新节奏更新，停稳或隐藏后停止。失焦等待 100 ms 后淡出 100 ms；系统关闭动画时直接切换，固定、编辑、菜单和拖放期间暂停收纳。
- 可开启/关闭露边，宽度可在 **1–12 个物理像素**间调节，默认 1；关闭后仍可悬停原窗口对应的边缘唤出，也可用热键或托盘找回。
- “更多 → 路径转换”提供分组/分类树形多选、全选/清空、半选状态及转换预览。以数据库目录为基准，同时转换程序路径和工作目录，跨盘失败保留原值。
- 每套菜单都按操作语义插入分隔线分段：项目右键为 打开／打开所在位置／复制路径 → 编辑／重新定位 → 管理员打开／原生菜单／桌面快捷方式／刷新图标 → 移动到／复制到 → 排序／路径转换 → 删除；分组与分类右键为 新建／编辑 → 排序／移动到分组 → 删除；“数据”子菜单把 打开数据目录 与 导出／恢复／备份 分开；托盘分成 窗口／开关／应用／退出 四段。窄窗口的项目区几乎点不到空白，所以空白右键那一段（多选整理／添加项目…／添加文件…／图标大小／列表查看／按名称排序）由同一处构造，同时挂在空白右键和标题栏“更多”里，命令号 30 与 40–46 共用一份分发。名称统一在编辑页修改。原生菜单按鼠标物理坐标定位，二级默认向右展开，仅屏幕边缘空间不足时由 Windows 翻转。
- 添加/编辑窗口采用单页滚动表单，名称/图标/分类、目标/参数/工作目录、别名/备注分区排列，不再折叠更多选项；程序与快捷方式另提供普通／最大化／最小化的打开方式，其他类型不显示该字段。所属分类改为分组→分类的树状选择（与批量整理共用同一棵树），支持展开收起、方向键与 Enter，Esc 只收树不丢编辑。类型为“应用”时目标不再手输：点“从应用列表选择”打开本机 AppsFolder 列表，可按名称或标识筛选，双击或”添加”即回填，并顺带取回该应用自己的图标；这个列表窗口跟随编辑器，不会把停靠条带到前台。删除确认显示对象名称、迁移目标或“不迁移”勾选，以及文件保留说明。
- Explorer 文件拖入、多选添加，程序/文件/目录/网址/快捷方式/AUMID，优先 256 像素的 Shell 图标提取（打包应用按 AUMID 从 AppsFolder 取图标，网址联网取网页自己的图标：`<link rel=icon>` 优先，退到 `/favicon.ico`）和自定义内嵌图标，JSON 导出恢复、一致性数据库备份继续支持。网址图标只在添加/编辑保存、拖入之后和手动“刷新图标缓存”时抓取，启动回填不联网。
- 关闭按钮隐藏；默认 **Ctrl + Alt + Space**、托盘或第二实例找回。可在“呼出与隐藏”录制新组合键或恢复默认；注册冲突时保留原设置。固定会置顶；游戏保护优先于固定和所有动画。

项目网格不再保留点击或右键选中高亮，搜索键盘导航仍显示当前结果。拖动需按住至少 180 ms 并移动至少 12 DIP；快速大幅滑动松手取消操作，菜单关闭清除指针状态。

主窗操作提示在 6 秒后自动消失，也可点击关闭。拖动项目的左右半区分别表示插入目标之前/之后，插入线提示位置。

项目编辑仍保留未保存保护；删除和恢复仍需明确确认。相对路径以数据库目录为基准。启动失败区分目标已删除、网络位置暂不可用、设备未就绪、无关联应用与已取消授权；前三类就地提供重新定位，只替换路径，保留参数、工作目录与打开方式，并丢弃属于旧目标的内嵌图标。没有 Everything、磁盘索引、账号、云服务或皮肤。

## 数据恢复

业务数据与设置保存在 `diascia.db`。运行中不要只复制主文件作为备份，数据可能仍在 WAL 中；使用设置里的“备份”或“导出”。

“恢复”只接受本应用版本 1 的 JSON，确认后替换当前数据。数据库 `.db` 备份可在退出应用后复制到一个**新的空目录**，命名为 `diascia.db`，再用 `--data-dir` 打开检查，同时保留原数据目录。

导出/备份不覆盖已有同名文件，请使用新名称。本项目不导入任何旧版数据；未知 JSON 字段/类型和非版本 1 的数据库一律拒绝读取、不作改写。

## 数据兼容与当前边界

数据库与 JSON 导出都是版本 1，Diascia 只读写版本 1。版本号随“这是新软件”的定位归零重开，因此 0.3–0.5 开发阶段留下的库、任何非版本 1 的库和外部结构的库都会被拒绝且不作改写；设置项允许缺字段（读取时取默认值），但不接受未知字段。

本项目不做旧版数据迁移。浏览器/OLE 已有原生格式与生命周期回归，真实浏览器拖放、混合 DPI 和显示器热插拔仍需人工验收。游戏保护保留现有 500 ms 复核和显示前检查；尚未做 osu!lazer 真机矩阵。Narrator、高对比度、热插拔显示器及真实跨 DPI 鼠标操作仍需要人工验收。

应用上下文菜单使用 Fluent 自绘图标、文字、浅深色、悬停圆角与弹窗裁剪，Windows 负责菜单跟踪和三级展开；“Windows 原生菜单”单独调用 Shell，控件浮层由 Slint 绘制，托盘继续使用原生菜单；隐藏再呼出保留完整重绘桥接。内部桥接仍固定 Slint 1.18.0。

## 开发验证

默认路径全程不需要前台：门禁不移动鼠标、不点亮窗口，可以在你干别的事情时跑。

```powershell
.\scripts\verify.ps1                      # 格式 + clippy(-D warnings) + 全部离屏测试 + release 构建 + exe 体积
.\scripts\verify.ps1 -Release -Machine    # 追加第二层机器验收：只有这一步会抢前台
```

### 第一层：离屏（默认，`cargo test --all-targets --locked`）

- `tests/partial_repaint.rs`、`batch_panel_grid.rs`、`titlebar_search.rs`、`tooltip_render.rs`、`tooltip_popup_render.rs`、`ui_interactions.rs` 各自安装一个 `MinimalSoftwareWindow` 平台，用 `dispatch_event` 驱动回调、把界面光栅化进自有的像素缓冲。`slint::platform::set_platform` 每进程只能调一次，所以一个测试二进制只可能有一种平台。
- `tests/menu_trees.rs` 只依赖 `diascia::menus` 的数据：菜单内容、分段、命令号与 `region()` 归属、置灰条件、字形都在这里被钉住，既不建窗口也不碰 GDI。原生弹窗需要真 HWND，离屏窗口没有，所以**菜单内容只能作为数据被证明**。
- `src/platform/fluent_menu.rs` 的 `pixel_probes` 把 owner-draw 画进内存位图再用 `GetDIBits` 读回：分隔线粗细／缩进／颜色、行高 34、宽度夹在 206–340、悬停填充只在“选中且可用”时出现、禁用项用弱化色，100% 与 200% DPI 各测一遍。
- 看图：`DIASCIA_MENU_DUMP=target/menu.png cargo test --lib dump_every`（五套菜单、浅深两张图），`DIASCIA_TOOLTIP_DUMP` 同理。挑字形就靠这张图，不用开真菜单。
- 离屏能证明像素、几何、回调链路和数据；**证明不了**滚动视口（`visible-height` 在离屏布局下不成立）、DWM 圆角、真实 `TrackPopupMenu` 和 CPU。

### 第二层：机器验收（显式运行，会抢前台）

```powershell
cargo test --release --locked -- --ignored --nocapture
```

`src/app_regression.rs` 跑真实事件循环：弹主窗口和编辑器窗口并聚焦、放托盘图标、注册 Ctrl+Alt+Shift+F10 与 F9（你自己的实例在场时它的注册会失败，这是预期的）。它不联网、不启动目标、不写剪贴板、不建快捷方式。这个文件只允许**一个** `#[test]`（单实例互斥体和原生事件循环都是进程级单例），新的真实路径检查挂进 `check_picker_after_owner_close` 链尾、排在 `check_window_state` 之前。

### 第三层：真机指标（脚本从不发输入）

```powershell
cargo build --release --locked
.\scripts\probe.ps1 -Seconds 30                        # 采样后按事件打 p50/p95，并算呼出延迟
.\scripts\probe.ps1 -Perf -Seconds 300 -Label collapsed  # 附带 CPU/内存采样
```

探针用 `--data-dir target/probe-data` 起一个独立实例（互斥体按数据目录哈希命名，不会和你正在用的那个冲突），设 `DIASCIA_METRICS` 收集 `时间,事件,值`，然后**等你自己操作**——脚本从不发送鼠标或键盘事件，因为合成输入会移走使用者的指针、点到桌面上的任何程序。**千万不要**把探针指向真实数据目录：那会把正在使用的启动器拽到前台。

离屏渲染支持浅深色、100%/150%/200% DPI、最小窗口及搜索/路径转换面板，但不等同于原生窗口验收。仍需人工过一遍：真实浏览器拖放、混合 DPI 与显示器热插拔、Narrator／高对比度，以及真开一次右键菜单，确认字形、分段和圆角与离屏图一致。
